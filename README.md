# QRoute Web Demo

QRoute 是面向企业量子应用团队的统一接入与任务路由前端演示。本阶段覆盖“资源接入—任务匹配—任务执行—运营管理”的任务闭环：校验项目与后端权限、路由约束、账户接入和预算；创建任务并跟踪异步状态；查看结果、费用归属、操作日志和历史记录。项目使用原生 HTML、CSS 与 JavaScript，无需安装依赖，也不连接外部服务。

## 启动

在仓库目录运行：

```bash
python3 -m http.server 4173
```

浏览器访问 `http://localhost:4173`。

## 演示流程

1. 使用顶栏“演示身份”切换项目管理员 / 开发者。管理员可在“项目”查看并管理成员、供应商授权、月度预算、BYOK 连接与项目用量；开发者看不到项目管理资料，只能访问被授权项目的任务和结果。
2. 在“提交任务”选择项目和框架，调整任务规模、必须真机/模拟器要求、供应商范围、区域、完成时限、预算及需排除的设备。
3. 查看候选后端。只有通过项目供应商授权、资源健康、容量、框架、接入凭据、区域、时限、预算和额度检查的候选才进入路由排序。
4. 在指定后端、性能优先、成本优先中选择策略。指定设备不可用时会阻止提交，不会静默切换；自动策略会解释命中结果与主要取舍。
5. 项目管理员可选择企业平台额度或项目 BYOK 连接；开发者使用已配置的任务接入方式提交。提交后获得唯一 QRoute 任务 ID 和模拟后端任务 ID。
6. 在任务详情逐步推进适配、排队、执行、结果回收；可发起取消并等待模拟后端确认，查看日志、测量结果、费用与失败处理建议。
7. 在任务列表刷新或重新打开页面，恢复已保存的任务状态；可对失败任务重新载入参数，复核后再提交。
8. 在“后端目录”查看资源状态和能力；项目管理员可在“项目额度与 BYOK”管理项目连接及费用归属。

## 第一阶段范围

本阶段只完成任务闭环，不包含编译优化服务、编译优化开关、购买/开通入口或独立编译优化工作区。“适配中”是常规提交准备过程，不代表可选优化服务。编译优化与更高级的智能路由属于后续阶段。

## 模拟边界

页面明确标注为演示环境。供应商、设备、质量分、性能、任务、凭据、状态、费用和结果均为虚构数据。不会连接真实量子硬件、API、账户、支付服务或外部服务。密钥只显示脱敏占位符，不收集、不发送，也不保存。任务 ID、状态、路由快照、日志和模拟结果保存在当前浏览器的本地存储，以便刷新恢复；程序源代码不会写入本地存储。清除浏览器站点数据会删除这些项目、成员配置与演示任务。
